# 05 · 决策记录（ADR）

## D-001 项目方向

- **日期**：2026-10-13
- **状态**：已决定
- **决定**：做**插件合规与兼容性公共设施**（方向 A），并把**构成冲突检查**（方向 B）作为第二个模块。
- **范围**：CLI 体检与兼容矩阵**都做**——CLI 先行（快、可立刻产出数据报告），矩阵随后（更独家、数据会增值）。
- **理由**：生态已有 4,508 个插件、月增近千，而"代码写得对不对、在这个 DSH 版本上还能不能用"没有任何工具回答；现有邻居（doctor / testkit / trust-check / my-guardian）覆盖的是相邻格子。
- **发布口径**：**点名 + 只陈述事实**；发布前**通知相关作者**；每条结论必须带文件:行:证据:官方出处，不做道德审判。
- **许可证**：Apache-2.0（含专利授权，适合基础设施）。
