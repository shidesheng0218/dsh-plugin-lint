# W1 · couples the plugin to a Harness Client package

- **Level:** warn
- **Source:** dsh plugin-development / references/practices.md

## What it checks

Detects a client entry that imports a `@deepseek-ai/dsh-client-*` package, or a manifest that declares one as a dependency.

## Why it matters

Those packages change without notice and a throwing component blanks the slot; the reference advises copying the primitive.

## Boundary

Official first-party packages are exempt because they ship with the browser module table. One finding per surface, not per package.
