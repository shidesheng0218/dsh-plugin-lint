# E7 · the published artifact contract is broken

- **Level:** error (missing subpath export/bin target); warn (icon format/size, stale `files` entry)
- **Source:** dsh plugin-development / references/host-plugin.md

## What it checks

- Every non-pattern `exports` subpath other than `.` and `./client` resolves to an existing file.
- Every `bin` target exists.
- `icon` uses SVG, PNG, JPEG, or WebP and is at most 256 KiB (warnings).
- Every non-negated `files` entry matches at least one packed file (warning).

## Why it matters

A subpath export or bin that resolves to nothing fails at import or command time, after the package has been published. A stale `files` entry usually means a path was renamed or a build output was not produced.

## Boundary

The rule runs in the publish phase and is skipped in `--phase author`. It checks existence, not that a file is semantically the right one; `files` warnings are suppressed when the packlist cannot be modelled completely.
