# I3 · locale metadata is not published

- **Level:** warn
- **Source:** dsh plugin-development / references/host-plugin.md

## What it checks

Reports a locale directory that is not exported, or whose `en.json` is not covered by `files`/ignore rules.

## Why it matters

Display metadata is read through the locale subpath; missing metadata shows as a fallback title and default artwork.

## Boundary

The rule checks the locale directory, the exports map and the packlist; it does not judge translation quality.
