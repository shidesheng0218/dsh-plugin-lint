# E4 · declares a client half without a client entry

- **Level:** error
- **Source:** dsh plugin-development / references/ui-plugin.md

## What it checks

Checks that `dsh.client` has an `exports["./client"]` that resolves to a file, accepting only a string or a string `default`.

## Why it matters

The client registry does not accept `import`/`require`-only conditions or arrays.

## Boundary

`--phase author` downgrades an unbuilt client output to info when a build script exists.
