# W2 · folds session state by rescanning the log

- **Level:** warn
- **Source:** dsh plugin-development / references/practices.md

## What it checks

Detects a `session/event` listener whose inline body reads `.events` or calls `eventsBackwards(` without using `ctx.sessionProjections`.

## Why it matters

A per-event rescan costs the whole session on every append; a projection folds incrementally and keeps the same reference for ignored events.

## Boundary

The check is scoped to the next brace block after the registration and is a hint, not a proof.
