# E3 · manifest references a file that is not in the package

- **Level:** error
- **Source:** dsh plugin-development / references/host-plugin.md

## What it checks

Checks that the host entry (`exports["."]` before `main`), client entry, bundle patch, and icon exist on disk.

## Why it matters

Management pages read these paths without activating the plugin; a missing artifact is a broken package.

## Boundary

In `--phase author`, a missing build output (`lib/`, `dist/`, ...) with a build script is an info hint, not an error. A stale `main` shadowed by a working `exports["."]` is also info.
