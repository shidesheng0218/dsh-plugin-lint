# E6 · a DSH peer range excludes the target runtime

- **Level:** error
- **Source:** dsh app-boot / README.md (peer admission)

## What it checks

Requires every `@deepseek-ai/dsh` / `@deepseek-ai/dsh-*` peer range to accept the target runtime passed with `--dsh-version`.

## Why it matters

The host checks peerDependencies before importing a plugin; every declared range must match, and prereleases participate in range matching.

## Boundary

Missing peers impose no constraint. `workspace:^|~|*` are substituted with the runtime version. Ranges outside the supported grammar are reported as info, never as errors. `dsh.compatibility.dshReleases` is a declaration, not the host gate.
