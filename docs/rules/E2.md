# E2 · client bundle factory id matches nothing the loader can ask for

- **Level:** error
- **Source:** dsh plugin-development / references/ui-plugin.md

## What it checks

Detects `__ModuleLoader__.load({ id: "..." })` when the id is neither the package name, `<package>/client`, nor a patch row inside the package's own namespace.

## Why it matters

The browser module table is keyed by the id the loader asks for; a bundle that registers another id leaves the client half unreachable.

## Boundary

The loader strips a trailing `/client`; patch rows from other packages are not legal keys. A computed id is skipped.
