# E5 · published files omit an artifact the manifest depends on

- **Level:** error
- **Source:** dsh plugin-development / references/host-plugin.md

## What it checks

Compares the manifest artifact list against npm's packlist semantics (`files`, root `.npmignore`/`.gitignore`, nested ignore files).

## Why it matters

This class of bug passes local testing and only appears after publish.

## Boundary

The rule is skipped when the packlist cannot be modelled completely (symlinks, bundled dependencies, unreadable directories).
