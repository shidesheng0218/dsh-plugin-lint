# I2 · ships no display metadata

- **Level:** info
- **Source:** dsh plugin-development / references/host-plugin.md

## What it checks

Reports a missing top-level `icon`, or locale files without a `meta.title`/`meta.description`.

## Why it matters

Management cards and the settings inventory read these without activating the plugin.

## Boundary

Only `locale/{en,zh,zh-CN,ja,ru}.json` are read today; another language is not a finding.
